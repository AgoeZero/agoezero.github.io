Skin Disease Detector

An experimental image-classification application that uses a lightweight convolutional neural network to classify images into categories represented in its training dataset.

About the project

The application is built with Scheme and LambdaNative. Its model is trained using Python, TensorFlow and Keras, then converted for lightweight on-device inference with TinyMaix.

Dataset

Training data comes from the Skin Disease Dataset on Kaggle.

The project uses eight dataset categories covering bacterial, fungal, parasitic and viral infections. Model predictions should be interpreted within the limitations of this dataset.

Technology

  • Scheme and LambdaNative
  • C and TinyMaix
  • Python, TensorFlow and Keras
  • TensorFlow Lite model conversion and quantization
Medical disclaimer: This application is intended for educational and experimental research purposes only. It is not a medical diagnostic tool and must not replace assessment, advice or treatment from a qualified healthcare professional.
