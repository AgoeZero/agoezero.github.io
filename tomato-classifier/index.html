Tomato Leaf Disease Detector

Tomato Leaf Disease Detector is an image-classification application that uses a lightweight convolutional neural network to identify tomato leaf diseases from images.

About

Built with Scheme and LambdaNative, the application uses a custom-trained machine learning model developed with Python, TensorFlow and Keras. The model is converted and optimized for on-device inference using TinyMaix, allowing image classification to run locally without requiring a continuous internet connection.

Features

  • Classifies tomato leaf images into disease categories.
  • Uses a custom-trained convolutional neural network.
  • Runs image classification locally on the device.
  • Uses TinyMaix for lightweight and efficient model inference.
  • Explores the application of artificial intelligence in agriculture and plant disease detection.

How it works

  1. Train a convolutional neural network using labelled tomato leaf images.
  2. Convert and quantize the trained model for efficient deployment.
  3. Integrate the model into the LambdaNative application.
  4. Run image classification locally using TinyMaix.

Technology

  • Scheme and LambdaNative
  • C and TinyMaix
  • Python, TensorFlow and Keras
  • TensorFlow Lite model conversion and quantization
