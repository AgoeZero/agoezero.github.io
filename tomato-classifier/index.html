Tomato Leaf Disease Detector

A lightweight image-classification application designed to identify tomato leaf disease categories using a custom-trained convolutional neural network.

About the project

The project combines a Python-based model training workflow with a mobile application built using Scheme and LambdaNative. The model is prepared for efficient on-device inference, allowing classification to run locally without requiring a continuous internet connection.

How it works

  1. Train a CNN using labelled tomato leaf images.
  2. Convert and quantize the trained model for efficient deployment.
  3. Integrate the model into the LambdaNative application.
  4. Run image inference locally with TinyMaix.

Technology

  • Scheme and LambdaNative
  • C and TinyMaix
  • Python, TensorFlow and Keras
  • TensorFlow Lite model conversion and quantization
